Relay adds real-time collaboration to your Obsidian vault. Install the plugin and sign in, then join the Relay Server you were invited to, or share a folder from your own server and invite your collaborators.

## Before you start

Install [Obsidian](https://obsidian.md/download) and open the vault where you want to use Relay.

## Install Relay and sign in

Install Relay from Obsidian's community directory, enable it, and sign in to your Relay account. For the full steps, see [Install Relay for Obsidian](/guides/install-relay-for-obsidian/).

The rest of setup happens in Relay settings. For ways to open them on desktop and mobile, see [Open Relay settings](/guides/open-relay-settings/).

## Join a server you were invited to

If someone sent you a Share Key, paste it into **Enter share key** under **Join a Relay Server** in Relay settings, and click **Join**. Then open the server from your **Relay Servers** list and add its Shared Folder to your vault. For the full steps, see [Join from an invitation](/guides/invite-a-collaborator/#your-collaborator-joins).

## Share notes from your own server

If you're starting fresh, share a folder from your vault and invite the people you work with.

<ol class="guide-steps">
<li>
<h3 id="find-your-relay-server">Find your Relay Server</h3>
<p>When you sign up, Relay creates a starter Relay Server for you using your first name. You can use that one, or create another. For the full steps, see <a href="/guides/create-a-relay-server/">Create a Relay Server</a>.</p>
<p>Your starter server is hosted by Relay. To run a server on your own infrastructure instead, see <a href="/guides/choose-how-to-host-relay/">Choose how to host Relay</a>.</p>
</li>
<li>
<h3 id="share-a-folder">Share a folder</h3>
<p>Choose the server, then choose the folder from your vault that you want to share. The folder stays in your vault. For the full steps, see <a href="/guides/share-a-folder/">Share a folder</a>.</p>
</li>
<li>
<h3 id="invite-collaborators">Invite collaborators</h3>
<p>Send your collaborators the server's Share Key. Each one joins your Relay Server, then adds the Shared Folder to their own vault. For the full steps, see <a href="/guides/invite-a-collaborator/">Invite someone to collaborate</a>.</p>
</li>
</ol>
